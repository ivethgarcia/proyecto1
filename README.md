# ⚽ Sistema de Tabla de Posiciones de Fútbol

Un sistema web moderno y responsivo para administrar torneos de fútbol, gestionar clubes, registrar resultados de partidos y generar automáticamente la tabla de posiciones con estadísticas detalladas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica de las vistas.
- **CSS3 & Bootstrap 5**: Diseño visual moderno, responsivo y adaptado para móviles.
- **Bootstrap Icons**: Iconografía deportiva y de interfaz.
- **JavaScript (Vanilla)**: Lógica de negocio y cálculo dinámico de estadísticas.
- **Supabase**: Base de datos en la nube y persistencia en tiempo real.
- **Git & GitHub**: Control de versiones y repositorio de código.

---

## 📂 Estructura del Proyecto

```plaintext
proyecto 1/
├── css/
│   └── estilos.css           # Estilos complementarios
├── js/
│   ├── equipos.js            # Módulo de administración de equipos (CRUD)
│   ├── partidos.js           # Módulo de registro y resultados de partidos
│   └── posiciones.js         # Lógica y renderizado de la tabla de posiciones
├── index.html                # Página principal (Tabla de Posiciones con diseño moderno)
├── equipos.html              # Registro y administración de clubes
├── partidos.html             # Registro de partidos y marcadores
├── styles.css                # Hoja de estilos principal (paleta deportiva y diseño responsivo)
├── .gitignore                # Archivos ignorados por Git
└── README.md                 # Documentación del proyecto
```
